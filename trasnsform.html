CSS 2D and 3D Transformations

2D Transformations

2D transformations change an element using the X and Y axes. They include rotate, scale, translate and skew.

Original
transform: none

No transformation is applied.

Rotate
rotate(15deg)

Rotates the element by 15 degrees.

Scale
scale(1.2)

Increases the size of the element.

Translate
translate(50px,20px)

Moves the element on X and Y axes.

Skew
skew(10deg)

Slants the element.

Combined
Multiple transforms

Applies more than one transformation.

X
translateX(40px)

Moves the element horizontally.

Y
translateY(30px)

Moves the element vertically.

3D Transformations

3D transformations work with the X, Y and Z axes. They can create depth and perspective effects.

Rotate X
rotateX(45deg)

Rotates around the X-axis.

Rotate Y
rotateY(45deg)

Rotates around the Y-axis.

Rotate Z
rotateZ(45deg)

Rotates around the Z-axis.

Translate Z
translateZ(50px)

Moves the element along the Z-axis.

Scale 3D
scale3d()

Changes size in 3D space.

Perspective
perspective()

Creates a depth effect.

Origin
transform-origin

Sets the transformation point.

Backface
backface-visibility

Controls visibility of the back side.

transform-style: preserve-3d

The preserve-3d property allows child elements to maintain their 3D position.

3D Child

Hover Transformation
